# Данные для домашнего задания 1

**Студент:** Садаков Дмитрий Андреевич  
**Группа:** Б05-331

**Датасет:** UCI Online Retail.

- Первоисточник: https://archive.ics.uci.edu/dataset/352/online+retail
- Прямая загрузка: https://archive.ics.uci.edu/static/public/352/online+retail.zip
- Цитирование: Chen, D. (2015). *Online Retail*. UCI Machine Learning Repository.
  DOI: https://doi.org/10.24432/C5BW33
- Лицензия: CC BY 4.0.
- Файл внутри архива: `Online Retail.xlsx`.
- SHA-256 ZIP: `f5385cbb54bbebf7196389109c6b0621faab0c304e3702548165e71c84aede8b`.

Исходные 541 909 строк — позиции счетов интернет-магазина за 01.12.2010–09.12.2011.
После удаления точных дубликатов, отсутствующих CustomerID, отмен/возвратов,
неположительной цены и служебных артикулов остаются **391 150 строк покупок,
4 334 пользователя и 3 659 товаров**. Случайная подвыборка не используется.
Число уникальных user–item пар и разреженность приводятся в ноутбуке и
`results/dataset_summary.json`. Повторные покупки сохраняются; частота определяется
числом разных счетов, а не количеством единиц товара.

CustomerID — пользователь, StockCode — объект, InvoiceDate — время взаимодействия.
Метаданные FM: страна пользователя, слова названия товара, ценовой сегмент по
исторической медиане UnitPrice. Все преобразования и словари обучаются только
на train (при refit — на train+validation).

`data_utils.load_raw()` автоматически получает архив, проверяет его SHA-256,
читает XLSX и создаёт локальный сжатый CSV-кеш. Исходные данные не включаются в GitHub.
