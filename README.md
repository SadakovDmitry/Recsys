Персональные top-10 рекомендации на UCI Online Retail. Самостоятельно реализованы
ItemKNN, iALS, EASE, факторизационная машина с метапризнаками и ALS с собственным
целевым сигналом. Пять основных моделей оцениваются по одному временному протоколу
на полном каталоге. Две дополнительные абляции проверяют влияние метаданных FM
и изменение таргета при фиксированных настройках ALS.

После очистки: **391 150 покупок, 4 334 пользователя, 3 659 товаров**.
Train — до 01.10.2011, validation — октябрь 2011, test — с 01.11.2011 до конца данных.
Основная метрика NDCG@10 выбирается до поиска. После выбора настроек выполняется
refit на train+validation. Метаданные вычисляются только по истории обучения.

### Воспроизведение

Рекомендуется Python 3.10 или 3.11. Фактическое окружение запуска записано в
[`hw1/results/environment.json`](hw1/results/environment.json).

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r hw1/requirements.txt
cd hw1
python checks.py
python run_notebook.py
```

В Windows активация окружения: `.venv\Scripts\activate`.
Нужен интернет для первоначальной загрузки ZIP с UCI (~23 MB). Данные сохраняются
локально в `hw1/.cache/`, их SHA-256 проверяется перед использованием. Кеш не входит
в репозиторий. Обучение выполняется на CPU; новый запуск повторяет подбор и test,
а не просто читает сохранённые метрики. Точное время зависит от компьютера.
Память EASE растёт квадратично по числу товаров; для запуска рекомендуется 8 GB RAM.

### Результаты и проверки

Финальный test, одинаковые 1 440 пользователей и полный доступный каталог:

| Модель | NDCG@10 | Recall@10 | Coverage@10 |
|---|---:|---:|---:|
| EASE | 0.10285 | 0.06324 | 0.27863 |
| ItemKNN | 0.09047 | 0.05378 | 0.26310 |
| CustomALS | 0.08773 | 0.05600 | 0.30469 |
| iALS | 0.08229 | 0.05154 | 0.35431 |
| FM с метапризнаками | 0.07382 | 0.04422 | 0.23676 |

EASE лидирует и на validation, и на test. Собственный target ALS увеличил точечную
оценку NDCG, но 95% парный bootstrap-интервал разности включает ноль. У FM добавление
метаданных снизило точечный NDCG относительно FM только с ID; соответствующий интервал
тоже включает ноль. В ноутбуке представлены обе абляции, интервалы и ограничения.
Два полных запуска дали одинаковые значения всех четырёх метрик на validation и test;
подробности — в [`verification.json`](hw1/results/verification.json).

- [`validation.csv`](hw1/results/validation.csv) — все 19 конфигураций.
- [`selected_params.json`](hw1/results/selected_params.json) — настройки, выбранные до test.
- [`test_results.csv`](hw1/results/test_results.csv) — пять основных моделей и две абляции.
- [`conclusions.md`](hw1/results/conclusions.md) — выводы с фактическими числами.
- [`paired_comparisons.csv`](hw1/results/paired_comparisons.csv) — парные bootstrap-интервалы.

Численные проверки: ALS против прямой взвешенной регрессии; EASE против независимых
ridge-задач с запрещённой диагональю; FM против явной суммы попарных взаимодействий;
проверки cosine, собственного target, метрик и исключения известных товаров.

### Публикация для сдачи

По условию нужна **ветка `master` публичного репозитория**, код — в папке **`hw1/`**.
В корень репозитория поместить этот README.md и .gitignore, рядом папку hw1.
Не загружать `.cache/`, `.venv/` и исходные ZIP/XLSX/CSV. Готовый архив для загрузки
содержит только исходный код, выполненный ноутбук и результаты.
Результат сдачи — ссылка на публичный репозиторий. Публикацию выполняет автор работы.
